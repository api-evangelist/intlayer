Intlayer is an internationalisation (i18n) framework for modern web applications, providing one way to manage multilingual content across React, Next.js, Vue, Svelte, Solid, Nuxt and Astro. Beyond the open-source (Apache-2.0) framework it operates a hosted CMS API at back.intlayer.org secured with OAuth 2.0 client credentials, publishes an RFC 9727 API catalog, a machine-readable agent authentication guide (auth.md), and ships an official MCP server both hosted (mcp.intlayer.org) and as a stdio package (@intlayer/mcp), alongside extensive documentation written for agents as well as humans.

**Areas:** i18n · Internationalization · Localization · React · Next.js · CMS · MCP

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Intlayer: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
